# חיטוב

אפליקציית מעקב חיטוב למובייל: שקילות שבועיות (משקל, מותן, זרועות), תמונות וסרטונים לכל שבוע, השוואת לפני/אחרי, יומן אימונים עם סטים ומשקלים, ותובנות שמחושבות מהנתונים.

## הפעלה בטלפון

1. ב-GitHub: **Settings ← Pages ← Build and deployment**. ב-Source לבחור **Deploy from a branch**, ב-Branch לבחור `main` ותיקייה `/ (root)`, ואז **Save**.
2. אחרי דקה-שתיים האפליקציה זמינה בכתובת `https://<שם-המשתמש>.github.io/hitov/`.
3. באייפון: פותחים את הכתובת ב-Safari ← שיתוף ← **הוספה למסך הבית**. באנדרואיד: Chrome ← תפריט ← **הוספה למסך הבית**.

## איפה הנתונים נשמרים

כל הנתונים נשמרים רק בדפדפן של המכשיר. שקילות ואימונים נשמרים ב-localStorage, ותמונות וסרטונים ב-IndexedDB. שום דבר לא נשלח לשרת ושום דבר לא נכנס לריפו הזה.

- **שמירת גיבוי** מורידה קובץ JSON עם השקילות, האימונים והיעד.
- **שחזור מגיבוי** טוען קובץ כזה, למשל במכשיר חדש. תמונות וסרטונים לא נכנסים לקובץ הגיבוי.

## הבדל מהגרסה ב-claude.ai

בגרסה שב-claude.ai הנתונים מסונכרנים בין מכשירים ויש צ׳אט עם מאמן AI שמכיר את הנתונים. כאן, כדף סטטי, הצ׳אט לא זמין.

## קבצים

- `index.html`: כל האפליקציה בקובץ אחד, בלי תלויות ובלי build.
- `manifest.webmanifest`, `icon*.png`, `icon.svg`: התקנה למסך הבית.
